# Changelog

## 0.1.0

- Release standard: definition of done for an LLM feature.
- Go/no-go and rollout checklists with abort criteria.
- Evaluation and incident-response playbooks.
- Metrics and instrumentation spec with event schemas, dashboards and alerts.
- Templates: audit round brief, review checklist, model card, ADR.
- Worked examples for a fictional document Q&A assistant.
- Tools: checklist linter, Wilson-interval release gate, offline link checker, with pytest tests.
- CI: pytest and the offline link check.
